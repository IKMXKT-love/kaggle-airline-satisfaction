# 平台期再复核：新表示与筛选方式

日期：2026-10-21，Asia/Taipei。用户本轮要求继续思考。本轮查阅作者解法、官方代码和论文，并对现有已保存预测做描述性核对；没有拟合新模型、运行基础模型推理、生成或上传提交。

## 结论与优先级

最值得继续追查的结构性线索是：**用仅在原始数据上微调的小语言模型生成条件似然比，再让强表格模型读取这个新表示。** 它有相邻比赛的具体作者消融，且与当前已知的 GPT-2 数字分词特征不同。不过，本场的完整公开输出、实际增量收益和可承受成本尚未建立，不能宣称已有把握达到 0.962。

最近一步最合理的低成本工作是**修补候选筛选方式**：对已下载、可复算的上游候选，采用匹配基线的联合正则堆叠，衡量条件增量。此前固定正权重混合只能否决对应使用方式；不宜让它成为排除一切候选信息的唯一入口。这是研究流程改进，不是已经发现新的提分结果。

当前最佳仍为用户反馈公榜 0.96187 的 `submission_public_pool_20261020.csv`。目标差距 0.00013 不能直接用离线差值填算，也不能承诺一次填补。

## 1. 本场实际证据：弱单模型可以承担有用的条件角色

检查当前五个已保存的逻辑回归拟合：**246 个预测成员中，67 个成员的系数在五个拟合中始终为负。** 系数正负、大小会受相关性、尺度和正则影响，本身不是贡献证明。

因此另对现有全部 11 个 TFM 成员做固定删除诊断：从每折现有评分中减掉该成员的已保存有符号贡献，其余系数保持原样，不重拟合、不搜权重。用秩和公式复算 AUC，原始 OOF 重建最大误差为 2.66e-15。

| 已有成员 | 单模型 AUC | 固定删除后的原生折平均变化 | 负向折数 |
|---|---:|---:|---:|
| TabFM | 0.958870844 | -0.000114681 | 5/5 |
| LimiX2 | 0.958473880 | -0.000050946 | 5/5 |
| Causilo，五折系数均为负 | 0.958275404 | -0.000014056 | 4/5 |

这些结果说明现有组合确实利用了部分较弱成员的条件作用。负系数允许抵消共同偏差，但本诊断不能识别偏差的具体因果来源。

**边界必须保留：**固定删除不是重新拟合的成员消融；这些成员已经在当前池内，再次加权它们不是未入池候选的公平测试。总体 OOF 还会受折间尺度偏移影响，所以表中使用原生折平均差，同时保存总体差。不能由这张表推断新 Kumo 或神经邻居一定有贡献，也不能把删除损失当作可回收的新收益。

核对耗时约 18.20 秒。协议、代码及逐折结果：`decision_review_20261021/signed_roles_protocol.json`、`audit_signed_roles.py`、`signed_roles_audit.json`。既有上游 OOF 依赖与历史选择限制仍然存在。

## 2. 相邻比赛的新线索：原始数据语言模型条件似然

本轮实际打开并读取 [S6E9 亚军解法](https://www.kaggle.com/competitions/playground-series-s6e9/writeups/2nd-place-solution)。作者报告，在原始 10,000 行上以 GReaT 风格微调 distilgpt2；将字段写成文本并随机排列，计算给定 Yes/No 标签时整行的条件对数似然差，再按四种固定字段顺序平均。作者报告，多种配方的似然表示及其下游成员相对其 Stack A 累计改善约 0.0001069；直接优化最终 AUC 的改善约 0.0000162。原始似然列在最终组合中已冗余，主要价值在于作为下游模型输入。这些是作者自报的开发验证结果，不是本场复现或单项私榜消融。

可迁移的机制是条件似然表示以及它与下游模型的配合，不能搬用涨幅。本场已有数字 token 特征、原始数据教师和 `gpx_gen_v1` 生成式成员；所核查模型卡描述后者按字段构建条件分布，尚未找到上述 distilgpt2 原始数据微调配方。这个覆盖缺口不保证它有用，私人上游也可能包含未披露的相似步骤。

迁移风险尤其具体：S6E9 有明确购买公式，本场是更复杂的满意度数据；语言模型可能重复已有教师，或主要学到无关的字符串频率。不能把“数据由语言模型生成”当作已被组织方确认的事实。

**当前不建议直接开训。** 原作者一个 10k 行配方已耗约 4.1 小时；本场原始数据更大、字段更多。这个记录足以否决未经测速的长跑，不能简单线性外推本机耗时。作者 GitHub 的本次公开仓库清单和其唯一公开 Kaggle 数据集没有提供这条路线的可用输出；本次本场检索也未找到可核验的对应 OOF。未据此断言全球没有公开实现。

若后续获得实现或输出，必须与已有原始数据教师比较，并检验“只把似然当一个分数”与“作为强模型输入”这两个不同问题。仅在弱单模型上获益不足以进入全量训练。

## 3. 为什么另外两条暂时不作主线

**局部检索与任务微调：**[LoCalPFN 原论文](https://arxiv.org/abs/2406.05207) 联合使用查询近邻上下文和任务微调，方法不同于随机固定上下文。其主要证据来自较早的 TabPFN；不能直接外推到已有全上下文 TabPFN-3.5 的强组合。[TabDPT-Turbo](https://arxiv.org/abs/2608.01400) 还通过长上下文预训练减少对检索的需求，说明“局部一定胜过全局”并不成立。此前本场有限 TabICL 微调及神经邻居的负结果继续保留。

[TabPFN 官方微调示例](https://github.com/PriorLabs/TabPFN/blob/main/examples/finetune_classifier.py) 推荐 80GB 显存 GPU，并说明示例超参数针对 Higgs。当前实测为 RTX 4060 Laptop、8188MiB 显存；官方建议不是所有微调的硬性最低要求，但不支持照搬示例并承诺低成本。没有为此下载权重或安装依赖。

**直接优化 AUC：**S6E9 亚军在已筛选的配方中有小幅成功；[S6E9 第九名](https://www.kaggle.com/competitions/playground-series-s6e9/writeups/9th-place-solution) 则报告所试 pairwise/AUC 损失未改善其现有组合。同场已保存源码还记录了排序残差未获益。它可作后备目标对照，没有证据把它称为大幅升级的首选。点式交叉熵并非原则上不能学出好的 AUC 排序。

## 4. 下一步的可执行设计，尚未运行

先只检验“固定混合是否漏掉条件增量”这一机制，复用现有 246 列与两套已下载的池外数组：Kumo set E 三组平均、ModernNCA 启发的神经邻居。保留当前相同原生五折、固定 C=0.003 和相同数值精度，比较：

1. 246 列匹配基线重新拟合；
2. 基线加 Kumo；
3. 基线加神经邻居；
4. 两者一起加入。

允许系数有正有负，不搜 C、种子、正负权重或非线性门控。后三组用于区分单独条件增量与成对作用；预先同时声明，不能事后只展示胜者。比较原生折平均差、总体 AUC、预测在 OOF/test 的变化及来源依赖。当前两条配方的先验都不高，重开低成本筛选的理由仅是本轮明确识别了原筛选的局限。

已有拟合记录支持这种小规模元模型比较在分钟级完成；仍以准备、拟合和核验累计 15 分钟为上限，保留检查点。不得重新训练全部基础模型。没有与目标相称的正向证据，就结束这项检查。此前 +0.0003 的昂贵扩展参考门槛继续保留，不把万分之几或百万分之几包装成突破。

这种检查只用于决定是否继续投入，**不是端到端独立验证**。跨来源基础 OOF 的间接标签依赖，不能由相同分折、重复随机分折、正则或配对标准误消除。新候选若通过，还要另写训练边界与可承担的确认方案。
