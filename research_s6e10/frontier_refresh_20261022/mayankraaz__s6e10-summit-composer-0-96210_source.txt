### CELL 8 code
%%writefile summit_composer.py
"""Summit Composer helpers. Reuse: add this notebook as an input, then `from summit_composer import *`."""
import numpy as np
from scipy.stats import rankdata


def pct(v):
    return (rankdata(np.asarray(v, dtype=np.float64), method='average') - 0.5) / len(v)


def hblend(M, main, corr, mix=(0.3, 0.7)):
    """F.A. Nina's h-blend: sort each row both ways, weight by member + position, mix the two sides (float32 like the original)."""
    n, sides = len(M), []
    for rev in (False, True):
        order = np.argsort(-M if rev else M, axis=1, kind='stable')
        s = np.zeros(n)
        for j in range(M.shape[1]):
            k = order[:, j]
            s += M[np.arange(n), k] * (main[k] + corr[j])
        sides.append(s.astype(np.float32))
    return (np.float32(mix[0]) * sides[0] + np.float32(mix[1]) * sides[1]).astype(np.float32)


def rabari_line(t, RC, V41, V43):
    """KRISH RABARI's line V34 + t*e, rebuilt from his measured points t = 1.25 (V41) and t = 4.5 (V43)."""
    a125, a450 = V41 - RC, V43 - RC
    return pct(RC + a125 + (t - 1.25) / 3.25 * (a450 - a125))


def compose(base3, fourth, teacher, teacher_w, main, corr, gate_amp=0.0):
    """Mix each member with the teacher (share gated by member disagreement), then h-blend."""
    M = np.column_stack(list(base3) + [fourth])
    w = teacher_w + gate_amp * (pct(M.std(axis=1)) - 0.5)
    return pct(hblend(M * (1 - w[:, None]) + w[:, None] * teacher[:, None], np.asarray(main, float), np.asarray(corr, float)))

### CELL 9 markdown
## 🎚️ The new lever: a reversed disagreement gate

Kirill's gate gives the teacher a **larger** share on rows where the four members **disagree** (`amp > 0`).
I measured the same idea on the composed recipe and found the sign flips there:

| base (Nina recipe on rabari's line, t = 10) | gate amp on the teacher share | public |
|---|---|---|
| no gate | 0 | 0.96208 |
| Kirill's direction | +0.02 | **0.96207** (lost a digit) |
| reversed | −0.02 | 0.96208, and my team jumped above every other 0.96208 team (rank evidence) |

At the summit the members already agree with each other on most rows. Where they agree, leaning harder on the CV-backed teacher helps.
Where they disagree, the public-climbed members carry information the teacher doesn't have, so the teacher should step back.

On V54 the teacher share is 0.45 instead of 0.188, so I scaled the amp in proportion: **−0.05** → **0.96210**. Twice that (−0.10) overshoots: 0.96209.

This notebook's file goes one step further. rabari's V54 is itself a "bold" move away from the plain composition (line t 10 → 12, teacher share 0.188 → 0.45,
CV-stack share 0 → −1, bolder member weights and doubled corrections). I extend that move ×1.5 and keep the −0.05 gate: also **0.96210**.
