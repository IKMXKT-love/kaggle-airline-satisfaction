# S6E10: What Each Step Was Worth

Which parts of this airline-satisfaction recipe are worth trying before spending more compute?

**TL;DR**
- Target encoding (+0.001346 AUC) and the original-data teacher (+0.000586) were the largest additions in the controlled, historical XGBoost ladder.
- Route/count and auxiliary blocks each added about +0.00014 there; their smaller live check is less convincing.
- Five matched model pairs gained +0.000096 to +0.000176 OOF AUC with ten-fold training. Test improvement was not established.
- Historical 13-member recipe: **0.961913 combiner CV / 0.96153 public LB** (7 October 2026). These are this recipe's scores.

| Priority | Spend time on | Decision boundary |
|---|---|---|
| First | Target encoding; original-data teacher | Largest measured ladder gains; preserve fitting boundaries and check original-row overlap |
| Next | Ten-fold training for a promising member | Positive historical OOF pairs; weigh recorded fitting cost, not promised test gains |
| Optional | Route/count and auxiliary blocks | Smaller gains; train+test recipe, cache dependency and environment sensitivity |
| Finally | Plain logistic regression on logits | Tested tree stacker did not beat it on this frozen member set |

**Execution boundary:** the live ladder re-executes the disclosed **train+test recipe**, including its cached train+test auxiliary file. It is not fold-clean and is not rebuilt fold-fitted. Full-data members are cached; only the 200k-row CPU ladder, one reusable example and combiners execute here.

def nested_stack(names, C=1.0):
    'Combiner CV: 5-fold logistic regression on saved member logits (weights refit per outer fold); returns pooled AUC, fold AUCs, OOF stack scores.'

## Evidence before extra complexity

The historical ladder used 699,635 rows, identical five-fold partitions, seed 42, XGBoost depth 8 and learning rate 0.02. Each gain is conditional on the preceding blocks; route and counts were added together, so their effects cannot be separated.

The **fresh CPU re-execution** below keeps the prior 200,000-row stratified subset, three folds and LightGBM settings. Category vocabulary, route profiles and counts still use all train+test predictors; the auxiliary file is loaded, not regenerated. Target means use only fitting labels, with early-stopping rows separated first. This repeats the inherited recipe, not an independent confirmation or a new fold-fitted experiment.

def route_profile(full):
    'Per exact Flight Distance: mean of every other column, plus the route size. Label-free.'
    g = full.groupby(FD)
    out = pd.DataFrame({f'fdm_{c}': g[c].transform('mean').astype(np.float32) for c in FEATS if c != FD})
    out['fd_cnt'] = g['Age'].transform('size').astype(np.float32)
    return out

def value_counts(full, cols=NUMS):
    return pd.DataFrame({f'cnt_{c}': full[c].map(full[c].value_counts()).astype(np.float32) for c in cols})

def te_codes(full):
    'Integer keys whose satisfaction rate is target-encoded inside folds.'
    def key(cols):
        code = np.zeros(len(full), dtype=np.int64)
        for c in cols:
            k = pd.factorize(full[c], use_na_sentinel=False)[0]
            code = code * (k.max() + 1) + k
        return pd.factorize(code)[0]
    return {'te_fd': key([FD]), 'te_age': key(['Age']), 'te_fd_age': key([FD, 'Age']), 'te_fd_class': key([FD, 'Class']),
            'te_fd_travel': key([FD, 'Type of Travel']), 'te_seg': key(['Age', 'Class', 'Type of Travel', 'Customer Type'])}

def target_encode(k_fit, y_fit, k_apply, smooth=20.0):
    prior = y_fit.mean()
    s = pd.DataFrame({'k': k_fit, 'y': y_fit}).groupby('k')['y'].agg(['sum', 'count'])
    return pd.Series(k_apply).map((s['sum'] + prior * smooth) / (s['count'] + smooth)).fillna(prior).to_numpy(np.float32)

def add_te(keys, idx_fit, y_fit, *idx_apply, smooth=20.0):
    '''Fold-safe target encoding.
    keys      : dict name -> integer codes for every row of `full` (train + test), e.g. te_codes(full)
    idx_fit   : the rows the model fits on (their labels are the only labels used)
    y_fit     : labels of idx_fit
    idx_apply : any other row sets to encode: early-stopping rows, the validation fold, test rows
    Returns (DataFrame for idx_fit, [one DataFrame per idx_apply]). Fitting rows get inner 5-fold encodings,
    so no row sees its own label; every other row set is encoded from all fitting rows.'''
    fit, apps = {}, [dict() for _ in idx_apply]
    for name, codes in keys.items():
        col = np.zeros(len(idx_fit), np.float32)
        for i, j in KFold(5, shuffle=True, random_state=0).split(idx_fit):
            col[j] = target_encode(codes[idx_fit][i], y_fit[i], codes[idx_fit][j], smooth)
        fit[name] = col
        for d, idx in zip(apps, idx_apply):
            d[name] = target_encode(codes[idx_fit], y_fit, codes[idx], smooth)
    return pd.DataFrame(fit), [pd.DataFrame(d) for d in apps]

    return logit(m.predict_proba(full[FEATS])[:, 1]).astype(np.float32)

## Use the guide within its limits

Try target encoding and the teacher first, test small feature blocks on matching folds, then consider extra folds or a simple combiner if their measured cost is justified.

- **OOF** means a base learner did not fit that row's competition target; some features still used its predictors. Five-fold/seed-42 evaluation groups mix base training folds (5, 10, and busyaprime seed 33). Combiner fitting is cross-fitted; the full base-and-selection procedure is **not nested**, and optimism is unmeasured.
- Historical GBDT target encodings included inner early-stopping labels before that split. Outer validation labels were excluded. The live example fixes that order, but does not repair cached OOF. At least three public members early-stopped on their validation folds; the other five were not fully audited. CV is potentially optimistic by an unmeasured amount.
- The original teacher retained 465/129,880 original rows near-matching 474 competition rows (347 train, 127 test; 21 exact). Exclusion effects and full-stack seed robustness were not measured. Two saved seeds of one ten-fold RealMLP scored 0.961398 / 0.961413; that is limited seed evidence, not stack robustness.
- Eight final members are public OOF. The historical rules audit did not explicitly resolve prediction-sharing or every source licence; this review makes no new eligibility claim. Scores are observational historical receipts, not a CV-to-LB calibration. Numeric input versions are unavailable; consumed-file hashes identify this execution in `input_manifest.json`.
