### CELL 0 markdown
# S6E10 | Experiment 7: Original-Survey Prior Transfer

**Competition:** Playground Series S6E10 — Predicting Airline Satisfaction  
**Target / metric:** `satisfaction` / ROC AUC  
**Change:** train a LightGBM teacher on the public original airline survey training split, then add its probability and logit as two features to the Exp 1–4 feature and Exp 6 cross-fitted ensemble pipeline.  
**Validation:** stratified 5-fold CV on competition rows only.  

The original dataset's held-out `test.csv` is not read. Exact source rows matching any competition train or test feature row are removed before fitting the source teacher. No TabPFN credentials or Exp 5 code are used.

### CELL 4 markdown
## Why Exp 7

Exp 2 scored 0.96045 and Exp 3 scored 0.95846 in the completed submissions, so the stronger multi-model synthetic-data pipeline is retained. The recurring weakness in earlier experiments is that they only learn from synthetic competition rows, even though a public original airline survey contains the same target concept and aligned predictors.

Public S6E10 solution research reports an original-data XGBoost model's `orig_proba` and `orig_logit` as useful predictive features. It also reports direct real-data weighted training among unsuccessful approaches. Exp 7 therefore transfers the external dataset through a source-trained teacher feature rather than mixing raw external rows into competition folds. This is a hypothesis to validate, not a guaranteed gain.

The source teacher is trained on the original dataset's `train.csv` only. Rows whose feature signature exactly matches any competition train or test row are excluded before teacher fitting. The original target is used only to train that teacher. Competition OOF folds, target encodings, and contextual profiles retain the Exp 1–4 / Exp 6 leakage controls.

The external Kaggle dataset is publicly accessible at no cost, matching the S6E10 external-data rule. Its Kaggle license field says `Other (specified in description)`; review the source description/license before reuse beyond this competition.

### CELL 6 markdown
## 3. Exp 7 model evaluation: cross-fitted OOF blend

Train the two LightGBM configurations and XGBoost from Exp 2 on each stratified competition fold using the Exp 4 contextual features plus the two original-survey teacher priors. For each validation fold, search a coarse simplex grid for blend weights using OOF rows from the other folds only. Apply those weights to the held-out fold to form nested meta-OOF predictions. Average fold-specific weights for test predictions. This avoids choosing weights on the same fold whose score is reported.

# Exp 4 conditional profiles + Exp 7 original-survey prior: leakage-safe CV.
context_keys = [
    ['Class', 'Type of Travel'],
    ['Class', 'Customer Type'],
    ['Class', 'Type of Travel', 'Customer Type'],
    ['Flight Distance'],
]

def add_context_features(reference, query, leave_one_out=False):
    """Group service means/counts from reference; leave each training row out."""
    out = pd.DataFrame(index=query.index)
    global_means = reference[service_cols].mean()
    for keys in context_keys:
        group_name = '_'.join(k.lower().replace(' ', '_') for k in keys)
        stats = (reference.groupby(keys, observed=True, dropna=False)[service_cols]
                 .agg(['sum', 'count']).reset_index())
        # pandas returns a two-level MultiIndex for aggregated columns; flatten before merge.
        stats.columns = keys + [f'{col}_{stat}' for col, stat in stats.columns[len(keys):]]
        merged = query[keys].merge(stats, on=keys, how='left', sort=False)
        first_count = None
        for col in service_cols:
            counts = merged[f'{col}_count'].fillna(0).to_numpy(dtype='float32')
            sums = merged[f'{col}_sum'].fillna(0).to_numpy(dtype='float32')
            if leave_one_out:
                own = query[col].to_numpy(dtype='float32')
                denom = np.maximum(counts - 1, 0)
                means = np.where(denom > 0, (sums - own) / np.maximum(denom, 1), float(global_means[col]))
                counts = np.maximum(counts - 1, 0)
            else:
                means = np.where(counts > 0, sums / np.maximum(counts, 1), float(global_means[col]))
            out[f'ctx_{group_name}_{col}_mean'] = means.astype('float32')
            out[f'ctx_{group_name}_{col}_delta'] = (query[col].to_numpy(dtype='float32') - means).astype('float32')
            if first_count is None:
                first_count = counts
        out[f'ctx_{group_name}_log_count'] = np.log1p(first_count).astype('float32')
    return out

    iter2 = m2.best_iteration or 500
    pred2_va = m2.predict(X_va, num_iteration=iter2)
    pred2_te = m2.predict(X_te, num_iteration=iter2)
    oof_lgb_wide[val_idx] = pred2_va
    test_lgb_wide += pred2_te / N_SPLITS
    auc2 = roc_auc_score(y_va, pred2_va)
    print(f"  [Model 2: LGBM Balanced] Best Iter: {iter2:4d} | Val AUC: {auc2:.6f}")
    
    # --- Train Model 3: XGBoost (if available) ---
    if HAS_XGB:
        try:
            # Prepare categorical features for XGBoost hist
            xgb_cat_cols = X_tr.select_dtypes(include=['category']).columns.tolist()
            X_tr_xgb = X_tr.copy()
            X_va_xgb = X_va.copy()
            X_te_xgb = X_te.copy()
            for col in xgb_cat_cols:
                X_tr_xgb[col] = X_tr_xgb[col].cat.codes.astype('int32')
                X_va_xgb[col] = X_va_xgb[col].cat.codes.astype('int32')
                X_te_xgb[col] = X_te_xgb[col].cat.codes.astype('int32')
            
            dtrain = xgb.DMatrix(X_tr_xgb, label=y_tr)
            dval = xgb.DMatrix(X_va_xgb, label=y_va)
            dtest = xgb.DMatrix(X_te_xgb)
            
            xgb_params = {
                'objective': 'binary:logistic',
                'eval_metric': 'auc',
                'learning_rate': 0.04,
                'max_depth': 7,
                'subsample': 0.85,
                'colsample_bytree': 0.65,
                'reg_lambda': 8.0,
                'reg_alpha': 0.05,
                'tree_method': 'hist',
                'device': 'cuda' if HAS_GPU else 'cpu',
                'random_state': SEED + fold,
                'n_jobs': -1
            }
            
            m3 = xgb.train(
                xgb_params,
                dtrain,
                num_boost_round=800,
                evals=[(dval, 'val')],
                early_stopping_rounds=50,
                verbose_eval=False
            )
            best_xgb_round = m3.best_iteration + 1 if m3.best_iteration is not None else 800
            pred3_va = m3.predict(dval, iteration_range=(0, best_xgb_round))
            pred3_te = m3.predict(dtest, iteration_range=(0, best_xgb_round))
            oof_xgb[val_idx] = pred3_va
            test_xgb += pred3_te / N_SPLITS
            auc3 = roc_auc_score(y_va, pred3_va)
            print(f"  [Model 3: XGB Hist]      Best Iter: {m3.best_iteration:4d} | Val AUC: {auc3:.6f}")
            del dtrain, dval, dtest, m3, X_tr_xgb, X_va_xgb, X_te_xgb
        except Exception as e:
            print(f"  [Model 3: XGB Hist Notice]: {e}; fallback to dual LightGBM.")
            HAS_XGB = False
            oof_xgb = None
            test_xgb = None

# --- Cross-fitted OOF blend weights ---
def make_weight_grid(n_models, step=0.2):
    units = int(round(1.0 / step))
    if n_models == 2:
        return [np.array([i / units, 1.0 - i / units], dtype=np.float32) for i in range(units + 1)]
    if n_models == 3:
        return [np.array([i / units, j / units, (units - i - j) / units], dtype=np.float32)
                for i in range(units + 1) for j in range(units + 1 - i)]
    raise ValueError(f"Expected 2 or 3 base models, got {n_models}")

model_oof = [oof_lgb_deep, oof_lgb_wide]
model_test = [test_lgb_deep, test_lgb_wide]
model_names = ["LGBM deep", "LGBM balanced"]
if HAS_XGB and oof_xgb is not None:
    model_oof.append(oof_xgb)
    model_test.append(test_xgb)
    model_names.append("XGBoost hist")

ranked_oof = np.column_stack([(rankdata(pred) - 0.5) / len(pred) for pred in model_oof])
ranked_test = np.column_stack([(rankdata(pred) - 0.5) / len(pred) for pred in model_test])
weight_grid = make_weight_grid(len(model_oof), step=0.2)
nested_meta_oof = np.zeros(N_TRAIN, dtype=np.float32)
fold_weights = []

for fold_id in range(N_SPLITS):
    valid_mask = fold_ids == fold_id
    meta_train_mask = ~valid_mask
    best_score = -np.inf
    best_weights = None
    best_tie_break = -np.inf
    for weights in weight_grid:
        candidate = ranked_oof[meta_train_mask] @ weights
        score = roc_auc_score(y[meta_train_mask], candidate)
        # Prefer a less extreme solution when coarse-grid candidates are effectively tied.
        tie_break = -float(np.sum((weights - 1.0 / len(model_oof)) ** 2))
        if score > best_score + 1e-10 or (abs(score - best_score) <= 1e-10 and tie_break > best_tie_break):
            best_score = score
            best_tie_break = tie_break
            best_weights = weights
    nested_meta_oof[valid_mask] = ranked_oof[valid_mask] @ best_weights
    fold_weights.append(best_weights)
    fold_auc = roc_auc_score(y[valid_mask], nested_meta_oof[valid_mask])
    print(f"Meta fold {fold_id + 1}: weights={np.round(best_weights, 2).tolist()} | held-out AUC={fold_auc:.6f}")

final_weights = np.mean(np.vstack(fold_weights), axis=0)
final_weights = final_weights / final_weights.sum()
final_test_preds = ranked_test @ final_weights
print("\nBase pooled OOF AUCs:")
for name, pred in zip(model_names, model_oof):
    print(f"  {name}: {roc_auc_score(y, pred):.6f}")
print("Fold-specific weight mean:", np.round(final_weights, 3).tolist())
print(f"Nested meta-OOF ROC-AUC: {roc_auc_score(y, nested_meta_oof):.6f}")
print(f"Total Training & Validation Time: {time.time()-total_t0:.1f}s")
print(f"{'='*60}")
