# 原始独有评分的额外信号准入检查

目标：检查原始数据的 Inflight service 在已有共同21字段之外，是否为满意度提供足够明确的可泛化预测价值，再决定是否值得做迁移或蒸馏。当前最佳公榜仍为用户反馈0.96187，四个最佳文件保持原样。

这列在比赛训练/测试中都不存在。真实值只能用于原始域教师，不能当成比赛行已知特征。已有联合表示三臂失败，因此不能直接叠加辅助头并声称更有把握。这个检查尚不验证比赛提分，也不测仅21字段学生是否能学会教师；源教师胜出是资源准入证据，不是迁移收益证明。

## 文献与约束

- Yang等，NeurIPS2022，Toward Understanding Privileged Features Distillation in Learning-to-Rank，https://papers.nips.cc/paper_files/paper/2022/file/aa31dc84098add7dd2ffdd20646f2043-Paper-Conference.pdf ，§3.1/3.2区分全字段教师与同字段自蒸馏；§4显示更强教师并不必然产生更强学生。该文任务是查询内NDCG排序，部分标签人为生成，且Table2按测试NDCG选checkpoint；不能把论文收益直接作为本场AUC预期。
- Provodin等，Rethinking Knowledge Transfer in Learning Using Privileged Information，https://arxiv.org/abs/2408.14319 ，提示需要区分额外信息与模型变化，不能仅用有额外字段的教师胜过学生来归因。已读作者摘要及研究机构出版元数据；OpenReview正式版PDF当前有浏览验证，未完整获取正式版正文。
- 本地v3_features.auxiliary从已裁剪21字段的表建立辅助目标，没有使用这一独有评分。已有同场作者代码主动丢弃该列；其“生成器未见过该列”是作者注释，未作为已经独立验证的官方生成机制。

## 固定对照与划分

从两个原始CSV合并，按共同21字段屏蔽与比赛train/test完全重合的原始行。比赛满意度标签不进入本轮拟合、选择或评分。

固定seed20261022，以原始满意度分层留出25%作源域外层评分。其余75%内再分层留出10%选轮数。每组先在内部拟合/停止，再从头重训完整75%，外层只最终计分一次。

三组同XGBoost：A共同21字段；B共同21字段+真实Inflight service；C共同21字段+分区内随机打乱的Inflight service。C控制增加一列及其边际分布本身的影响，打乱不使用标签，拟合/停止/计分分别打乱，完整重训重新固定打乱。禁用id及Unnamed索引列，不做目标编码。

树深6、learning_rate .04、min_child_weight5、subsample .9、colsample_bytree1、lambda5、hist/CUDA、4CPU线程、相同随机种子。每组最多1200树，内部AUC早停100轮，完整重训使用内部选定树数。预处理类别词表仅拟合相应拟合区，四个文本类别用原生类别，其余数值float32。记录相同1200轮上限下的选定轮数，不声称实际树数相同。

## 资源与停止

首次本轮数据读取至核验累计900秒，包含输入哈希、屏蔽、资源探针、6次正式拟合与独立预测重建。探针在内部拟合行上做60树，参数丢弃，无停止/外层评分；按后40树的耗时保守估算6次满1200树，乘1.5后加90秒核验余量，超预算不启动正式拟合。保留原时钟，不因错误重置。源域教师初筛不写比赛提交CSV，不修改最佳四个文件。

B需同时相对A和C在源域外层AUC至少+0.0005、固定预测配对95%区间下界大于0，并且logloss不比两组差，才有进入后续迁移设计的依据。这是资源优先级门槛，不是互信息检验定理，不代表可获得同幅比赛收益。未通过则当前额外字段教师配方停止，不追加种子或神经网络训练。

源域外层此前未用于本项模型选择，但原始数据已在历史教师中使用，不能把它描述为整个项目全新盲测。单次源域留出不等于完整多折验证，更不等于比赛泛化确认。
